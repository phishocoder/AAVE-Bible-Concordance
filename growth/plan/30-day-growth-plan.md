# 30-Day Growth Plan (beta) — AAVE Bible

## North star for 30 days
Increase beta sign-ups and collect feedback while keeping the experience ad-free.

Primary CTA: **Join waitlist** → https://officialAAVEbible.com
Secondary CTA: **Donate** → https://cash.app/$aavebibleapp

---

## Week 1 — Foundations (make conversion easier)
- Ensure the website has:
  - 1 clear hero message + 1 primary CTA
  - 3 feature bullets (Game / Translations / Verse images)
  - 3 screenshots or a short gif/video
  - 5-question FAQ
- Create a 15–30 sec demo clip (screen recording) for social
- Start a simple feedback capture:
  - “What did you come here hoping to do?”
  - “What was confusing?”
  - “What should we build next?”

## Week 2 — Social engine (TikTok/IG)
Post 4–6 short videos (15–30 sec) using one of these formats:
1) Verse image “before/after”
2) Quick game question challenge
3) Side-by-side translation comparison
4) 15-sec Sora animation + CTA to join waitlist

## Week 3 — Partnerships (church/community leaders)
- Outreach batch: 25 messages (mix of warm intros + cold partners)
- Goal: 5 conversations / 2 shares

## Week 4 — Tighten conversion + donations
- Add a “Keep the beta ad-free” donate module to website
- Ask for donations only after value delivery:
  - after someone creates a verse image
  - after 3 game sessions
  - after 5 translation lookups
