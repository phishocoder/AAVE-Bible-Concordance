# Growth (Revenue Enablement)

This folder is the non-code “make money” layer for AAVE Bible Concordance.

## Current strategy (Phil)
**Revenue model priority:**
1) App Store search
2) TikTok/IG
3) Email list
4) Church/community partnerships

**Monetization options in play:**
- C) Donations
- D) Ads
- E) Lead-gen into something else

## What’s inside
- `copy/` — landing page + App Store copy drafts
- `outreach/` — partner + community outreach templates
- `metrics/` — what to track weekly
- `assets/` — placeholders for screenshots/press kit later

## Operating cadence (weekly)
- Pick 1 growth lever to push this week (ASO, social, email, partners)
- Ship 1 artifact (copy update, outreach batch, content batch)
- Review metrics every Sunday (see `metrics/weekly-scorecard.md`)
