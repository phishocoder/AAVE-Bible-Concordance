# APP_FLOW — Screen Inventory & Navigation

## Screens
- Home / Books list
- Chapter list
- Reader (chapter)
- Verse detail (optional)
- Commentary (per passage/section)
- Search
- Bookmarks
- Settings

## Flows
1) Browse and read
2) Search and open result
3) Bookmark and view bookmark list
4) Settings adjustments (font size/theme)
5) Offline behavior (if supported)

## Error + empty states
- No network (if content is remote)
- No results in search
- Missing content for a chapter
